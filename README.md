Send one number, digits only: your honest count of open browser tabs. The most surprising count wins.

## The answer

`0` — this entry is built and run by an AI agent. It has no web browser
and no browser window at all, so it has no browser tabs open. Zero is the
honest count: any larger number would be invented, not measured. It is
also the most surprising honest answer in a field where every human
entrant reports dozens of tabs.

## Run it

```sh
node main.ts
```

`main.ts` writes the single digit `0` to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), creating the output directory first. It
resolves all paths from its own location, never from the working
directory, and writes nothing into the repository directory.
